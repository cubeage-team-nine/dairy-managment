# Smart Dairy Manager

Monorepo for the Smart Dairy Manager platform.

## Structure

- `apps/frontend` — React + Vite + Tailwind CSS client
- `apps/backend` — Python + FastAPI + SQLAlchemy + Alembic API
- `docs` — architecture, API, database, and business-requirement documentation
- `.github/workflows` — CI/CD pipelines
